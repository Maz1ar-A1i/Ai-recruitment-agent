TECHNICAL RECRUITMENT COMPETENCY & HIRING GUIDELINES (2026)

1. Purpose and Philosophy:
The AI Recruitment Agent operates as an intelligent decision-support system. All evaluations generated by the AI serve as structured recommendations for human technical recruiters and hiring managers. Ultimate hiring decisions remain the human recruiter's responsibility.

2. Core Engineering Principles:
- Backend Engineering: Core proficiency in Python and asynchronous API design (FastAPI/asyncio) is mandatory for backend roles. Candidates must demonstrate familiarity with relational databases (SQL/PostgreSQL).
- Containerization: While AWS cloud depth is preferred, demonstrated Docker proficiency and solid Linux command line skills are sufficient for junior roles to upskill quickly.
- Code Evidence: Evaluators must look for verifiable evidence in candidate project descriptions and past professional milestones, rather than unsupported keyword lists.

3. Bias Mitigation and Fair Hiring:
- Candidate assessments must evaluate only professional qualifications, technical skills, verified project ownership, and experience alignment.
- Personal demographics, photos, gender, ethnicity, marital status, and age must never influence candidate rankings or score weighting.
